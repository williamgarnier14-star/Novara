# Novara — Sites web sur mesure

Site vitrine de Novara (React, Vite, Tailwind), prérendu pour le référencement et les moteurs IA.

- `npm install` puis `npm run dev` pour travailler en local
- `npm run build` : construit le site et génère le HTML complet, les données structurées et `llms.txt`
- `api/avis.js` : fonction Vercel pour les avis clients
- Textes du site : `src/content.js`
- Stratégie GEO et textes pour les réseaux : `GEO.md`
